# Két sắt

Ứng dụng web lưu mật khẩu và hình ảnh, mã hoá ngay trên thiết bị (AES-256, khoá sinh từ mật khẩu chủ).

- Một tệp duy nhất: `index.html`, không cần cài đặt hay máy chủ.
- Dữ liệu chỉ lưu trong trình duyệt (IndexedDB), không gửi đi đâu.
- Quên mật khẩu chủ thì không thể khôi phục dữ liệu.

## Đưa lên GitHub Pages

1. Tạo repository mới trên GitHub.
2. Tải `index.html` (và `README.md`) lên repository.
3. Vào Settings, chọn Pages, chọn nhánh `main` và thư mục `/ (root)`, rồi bấm Save.
4. Sau ít phút, mở đường dẫn `https://TEN-CUA-BAN.github.io/TEN-REPO/`.
